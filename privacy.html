Privacy Policy

Last updated: March 4, 2026

What Gate Zero Does

Gate Zero is a travel creator intelligence platform that helps YouTube travel creators make data-driven decisions about where to film, when to post, and what content strategies are working. We analyse publicly available YouTube data to surface destination timing recommendations, content landscape insights, and competitive intelligence.

YouTube API Services

Gate Zero uses YouTube API Services to access publicly available data from the YouTube platform. By using Gate Zero, you agree to be bound by the YouTube Terms of Service and the YouTube API Services Terms of Service.

Our use of information received from YouTube APIs adheres to Google's Privacy Policy.

Gate Zero's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

What Data We Access

We access publicly available YouTube data, including:

  • Channel metadata (name, description, subscriber count, uploads playlist)
  • Video statistics (view counts, likes, comments, duration, publish dates)
  • Upload patterns and content frequency
  • Engagement metrics and performance trends

All data we access is publicly available and read-only. We do not access private videos, private playlists, or any data that is not already visible on the YouTube platform.

How We Use the Data

We use YouTube data to:

  • Power destination timing recommendations based on content performance patterns
  • Provide content landscape insights across 190+ travel destinations
  • Generate competitive intelligence for travel creators
  • Identify trending destinations and underserved content opportunities

Data Storage

We cache aggregated metrics in our database to minimise API calls and provide a responsive user experience. We store processed analytics — such as performance trends, destination scores, and aggregate statistics — rather than raw API responses. Cached data is refreshed periodically to ensure accuracy.

Local Storage and Cookies

Gate Zero uses your browser's local storage (chrome.storage.local) to store data necessary for the extension to function. This includes:

  • Authentication tokens — Supabase session tokens to keep you signed in. Managed by the Supabase SDK with automatic refresh and expiry. Cleared on sign-out.
  • User preferences — Settings such as your passport country, smart assist toggle, and dismissed notifications. Persisted until you change them or delete your account.
  • Cached API responses — Travel advisories (24-hour TTL), hotel and flight demand data (7-day TTL), visa requirements (30-day TTL), creator discovery results (24-hour TTL), and tourism data (24-hour TTL). Stale data is automatically purged.
  • Beta access status — Your beta authorization status. Cleared on sign-out.
  • Quota tracking — Daily API usage counters per key. Reset each day.

Gate Zero does not use browser cookies. We use chrome.storage.local, a browser storage mechanism functionally similar to cookies, to store the data listed above. All locally stored data is used solely to operate the extension and improve your experience. No raw YouTube API response bodies are persisted to local storage — only processed metrics and metadata.

You can clear all locally stored data at any time by signing out of Gate Zero or by clearing your browser's extension storage through your browser settings.

Revoking Access

You can revoke Gate Zero's access to your YouTube data at any time through Google's security settings:

  • Visit Google Security Permissions
  • Find "Gate Zero" in the list of connected apps
  • Click "Remove Access"

Revoking access will prevent Gate Zero from accessing any YouTube data associated with your Google account going forward.

User Data We Collect

When you sign up for Gate Zero, we collect:

  • Email address — provided when you join the waitlist or create an account
  • Usage analytics — basic product usage data to help us improve the platform

We do not sell, rent, or share your personal data with third parties for marketing purposes.

Data Deletion

You can request deletion of your data at any time by contacting us at the email below. We will process deletion requests within 30 days and confirm once your data has been removed from our systems.
